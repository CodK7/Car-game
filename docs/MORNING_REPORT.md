# تقرير الصباح — Wahiba Sands Off-Road (نسخة الويب)

صباح الخير. خلصت كل المراحل بالترتيب: A ثم B ثم W1 إلى W6. سجّلت كل مرحلة في commit خاص فيها.
اللعبة ويب (Three.js) وتشتغل في المتصفح، بدون Unreal ولا Epic. ما لمست Epic Games Launcher ولا ألعابك.

## طريقة التشغيل

```bash
npm install
npm run dev
```

بعدها افتح http://localhost:5173

| شي تبيه | الرابط أو الأمر |
|---|---|
| لوحة الضبط + عداد FPS | `http://localhost:5173/?debug` |
| الجودة | `?quality=low` أو `medium` أو `high` أو `auto` |
| سيارة LC70 | `?veh=lc70` |
| اللعب الجماعي | شغّل `npm run server` في terminal ثاني، وافتح `http://localhost:5173/?mp` في نافذتين |
| الاختبارات | `npm test` (77 اختبار، كلها ناجحة) |
| Smoke test بالمتصفح | `npm run smoke` (ناجح) |
| Build | `npm run build` (ناجح) |

**الأزرار:**
- W/S: سواقة وبريك، A/D: دركسون.
- 1/2/3: ‏2H/4H/4L. ‏[ ]: ضغط التواير.
- H: ونش. T: سيارة السحب. G: حفر.
- B: القائمة (مهمات، كراج، لون). P: وضع التصوير.

## وش ما تأكدت منه أو ما تحقق

- **الصوت** جربته بالأرقام والطيف بس، ما سمعته بأذني. اسمع `docs/evidence/w4_demo_I6.wav` و `w4_demo_V8.wav`، وقل لي رأيك.
- **High** أقل من 30 FPS على جهازك. اخترت `auto` يختار Medium أو Low.
- **اللعب الجماعي** جربته على نفس الجهاز بس (localhost، مع تأخير وفقدان مصطنع). ما جربته بين جهازين ولا على الإنترنت.
  - مع التأخير، كل لاعب يحس قوة الحبل بشكل مختلف شوي (السيرفر 28 kN، العميل 4.5 kN).
  - قرار انقطاع الحبل للسيرفر.
- **مهمة القافلة (convoy)** عبارة عن نقاط تفتيش بوقت، مو سيارات AI تمشي معك.
- **سيارة السحب** ذكاؤها بسيط: تمشي خط مستقيم، ما تلف حول الطعوس.
- **الطعوس الثانوية** من فوق شكلها منتظم زيادة. إصلاحها يبي إعادة GIS (‏7 دقايق)، ما سويتها.
- **LC70** على 35 psi في رمل عميق فيها تذبذب خفيف. ما تأكدت منه في المتصفح لفترة طويلة.
- **ظلال الكاميرا وهي تتحرك** شيكت عليها بالاختبار وبصور ثابتة بس.
- البيوت صناديق بسيطة، وأسلاك الكهربا مو مرسومة.
- لون السيارة لون واحد، بدون ملصقات.

## القرارات اللي اتخذتها بنفسي (Autonomous decisions)

1. نسخ الأدوات: Three.js 0.170، ‏Vite 8، ‏TypeScript 7، ‏Vitest 5.
2. الاختبارات تشغّل متصفح Edge الموجود عندك (ما نزّلت متصفح). أرقام FPS من نافذة حقيقية.
3. نقطة البداية: ممر بين الطعوس عند x 1650، z −2350، قريب من المنترب.
4. الوقت الافتراضي 16:24 (قبل الغروب). تغيّره بـ `?tod=12.3`.
5. وزن الـ Patrol ‏2500 كجم بدل 2.2 طن (المصادر تقول 2410–2640).
6. السيارتين أوتوماتيك افتراضياً (LC79 الحقيقية عادي بس). تغيّره بـ M.
7. الصوت حكمت عليه بالاختبارات بس، وحفظت ملفات WAV تسمعها الصبح.
8. خليت High أقل من 30 FPS بدل ما أشيل مؤثراته. Low و Medium يحققون الهدف.
9. اللعب الجماعي: كل لاعب يحسب فيزياء سيارته، والسيرفر يتحكم في الحبال والدخول (8 لاعبين بالكثير) والوقت.
10. القافلة نقاط تفتيش بدل سيارات AI.
11. أسعار القطع وقوة الحبال وتأثير القطع تقديرات، ومعلّمة ASSUMPTION في `docs/DECISIONS.md`.
12. زر R (إعادة) يتعطل إذا السيارة غارزة، عشان تضطر تطلّعها بالطرق الحقيقية (مثل ما يطلب البرومبت). مع `?debug` يشتغل.

التفاصيل كلها في `docs/DECISIONS.md`.
